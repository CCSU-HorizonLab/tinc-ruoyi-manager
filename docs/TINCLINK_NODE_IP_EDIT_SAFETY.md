# 普通节点编辑的地址保护

普通修改仅更新数据库元数据，不能同步迁移 Access Runtime 的 hosts 子网、客户端 /32 地址和路由。
因此已有节点的 networkIp 不再允许通过普通编辑变更。前端禁用该字段，Service 同时拒绝绕过页面的请求。

- 新建节点仍可指定 IP，并执行现有网段与唯一性校验。
- 保持原 IP、仅改备注或密码不受影响；省略 IP 表示不修改。
- 拒绝改址不依赖“已配置”状态，该历史状态可能缺失或滞后。
- 错误消息以 `TINC_NODE_IP_CHANGE_FORBIDDEN` 开头，沿用现有管理端异常响应格式。
- 拒绝发生在数据库更新、Runtime 调用和会话撤销之前。
- 独立地址迁移流程尚未实现，不建议通过直接修改生产数据库绕过限制。

验证：先用新增回归测试复现旧代码放行改址，再验证修复后的拒绝分支、相同 IP 的备注编辑、创建和密码重置。
2026-10-11：32 项相关后端测试、18 项前端测试通过，Vue 生产构建成功（独立输出目录 target/node-ip-validation）。
本次未更新生产服务器、数据库、Tinc 配置或客户端，不是线上迁移验收。
